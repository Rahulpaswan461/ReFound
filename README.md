# ReFound

A Chrome extension that replaces the new-tab page and brings forgotten bookmarks back
into view. Everything stays on your device: no account, no server, no tracking.

## Load it in Chrome

```bash
npm install
npm run build
```

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked** and choose the `dist` folder.
4. Choose your folders on the setup page, then open a new tab.

After changing code, run `npm run build` and click the reload icon on the extension's card.

## Tests

```bash
npm test
npx playwright install chromium
npm run test:e2e
```

## How it is organized

- `src/sync`: read-only mirror of Chrome bookmarks
- `src/recommend`: pure selection logic
- `src/store`: IndexedDB and settings
- `src/core`: daily picks, actions and stats
- `src/ui`: new tab, library, settings and setup
- `src/background.ts`: listens for bookmark changes

Wallpapers and icons are generated by `scripts/make-assets.mjs`.

The design and build plan are in `docs/superpowers`.
